SAFER is my Software Engineering Honours thesis completed at the University of New South Wales (UNSW). The project explores how retrieval-augmented generation (RAG), structured security knowledge and automated static analysis can improve the security of code generated by Large Language Models (LLMs).

Rather than relying solely on prompt engineering, SAFER retrieves relevant Common Weakness Enumeration (CWE) guidance, injects security context into the generation process, and automatically evaluates the generated code using security analysis tools.

---

## Overview

Modern LLMs are capable of generating functional code but often introduce security vulnerabilities. SAFER aims to reduce these vulnerabilities by integrating security knowledge directly into the code generation pipeline.

The framework consists of several stages:

1. Curate and preprocess security knowledge
2. Build a retrieval-ready security knowledge base
3. Generate vector embeddings
4. Retrieve relevant security guidance for each programming task
5. Generate code using LLMs with retrieved context
6. Evaluate generated code
7. Perform automated static security analysis

## Running the Pipeline

The pipeline is configuration-driven.

Run an individual stage:

```bash
python scripts/run_05_generate_code.py
```

Or execute the complete pipeline:

```bash
python scripts/run_all.py
```

Configuration files for each stage are located in the `configs/` directory.
